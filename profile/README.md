**So, what is DJI Pilot, exactly?**
DJI Pilot is a drone flight control app for Windows that pilots use to plan missions, fly DJI aircraft, and manage payload cameras from a single screen. Rather than being a general drone hobbyist app, it leans toward the workflows of pilots flying routine or repeat missions.

### Is DJI Pilot right for you?
| Feature | What it does for you |
|---|---|
| Live flight view | See telemetry, battery, and camera feed together |
| Waypoint missions | Plan a route on the map and fly it automatically |
| Payload camera control | Adjust gimbal and capture settings mid-flight |
| Flight log history | Look back at past missions after landing |

### Will it run on my machine?
- [ ] Windows 10 64-bit or later
- [ ] A modern 64-bit processor
- [ ] Enough RAM for Windows itself, plus headroom for live video
